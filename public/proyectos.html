Mis Proyectos Destacados

Backend / HTTP

Servidor Web Nativo en Node.js

Construcción integral de un servidor web utilizando la API nativa http y fs de Node.js. Soporta despacho de activos estáticos con detección MIME (HTML, CSS, JS, SVG, WebP, PDF), procesamiento de formularios por método POST y redirección 302 hacia página de confirmación.

Aspectos destacados: Cero dependencias externas pesadas, arquitectura basada en eventos asíncronos y página personalizada de error 404.
Node.js JavaScript HTTP API Bootstrap 5
Bases de Datos / SQL

Sistema Bancario Relacional (3NF)

Diseño y estructuración de una base de datos bancaria rigurosamente normalizada bajo la Tercera Forma Normal (3NF). Modela las operaciones de cuentahabientes, transacciones monetarias, créditos, cuentas de ahorro y contratos bancarios con restricciones de integridad.

Aspectos destacados: Eliminación de redundancias y dependencias transitivas, triggers de auditoría e indexación para consultas complejas.
MySQL Diagramas E-R Normalización 3NF SQL
